# Демонстрация меню «Мерлер»

Статическая копия страницы меню, собранная из рабочего сайта на WordPress скриптом `tools/export-static.js`. Здесь работают лента категорий, поиск и карточки блюд.

Админка, отправка отзывов и QR-код живут на настоящем сайте — GitHub Pages умеет только статику.

Исходники: [tima111333/merler](https://github.com/tima111333/merler)
